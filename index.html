What it does

Apply to the right jobs — not more jobs

A rich master profile drives everything. The engine only spends effort on roles that actually fit.

🔍

Sources fresh roles

Pulls LinkedIn postings from the last 24 hours for your target titles and locations.

🎯

Scores fit, then gates

An LLM returns a match score, strengths, and missing skills — low-fit jobs are dropped before any résumé is written.

✍️

Tailors, never fabricates

Selects and rephrases real experience per job description. A “do-not-claim” list keeps it honest.

🗂️

Editable Doc + PDF

Generates a Google Doc you can tweak, plus a matching PDF exported from the same source.

🧾

Logs everything

Every application — score, keywords, links, metadata — is stored in Postgres for tracking.

📊

Dashboard email

A daily summary with fit badges, strength/missing chips, and one-click links to each résumé.

Why it works

Design decisions

Profile as a superset, résumé as a projection. The master profile holds more than any résumé — so tailoring is selection + rephrasing, never fabrication.
Fit-score gate first. The highest-leverage step: LLM tokens are spent only on jobs worth applying to.
Code guards the LLM. Deterministic post-processing dedupes roles, drops hallucinations, caps projects, and extracts clean JSON — so model variance never breaks a résumé.
One source of truth. HTML → editable Google Doc → native PDF export means the Doc and PDF never drift.
Self-hosted. Your profile and applications stay on infrastructure you control.
